# Duel Masters Draft Room

A standalone browser prototype for drafting DM-01 against seven bots.

## Run

Open `index.html` in a browser. No install or server is required.

## Draft flow

- Draft three 15-card packs, one pick at a time.
- Seven bots pick from their packs; packs pass left in rounds one and three and right in round two.
- Track your 45 picks by civilization and restart for another draft.

The included card list is a compact practice pool, not a complete or verified DM-01 checklist. Packs are sampled from that pool, so duplicates can occur within a pack. Bot picks use a lightweight heuristic rather than full card rules or a competitive draft model.
